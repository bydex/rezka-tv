# Rezka TV: инструкция для Claude

Этот файл для ИИ-агента (Claude Code и подобных), которого попросили установить или доработать Rezka TV. Человеку обычный порядок установки описан в [README.md](README.md). Здесь то же самое, но с разделением «что делаешь ты» и «что делает человек», с точными командами и с граблями, на которые мы уже наступили.

Говори с человеком на его языке. Делай всё, что можешь, сам, и в каждый момент, когда нужны его руки, давай одну короткую понятную просьбу: что нажать на пульте или в каком окне.

## Чего агент не делает никогда

- **Не вводит пароли.** Ни от аккаунта Samsung, ни от HDrezka. Вход в Samsung в Certificate Manager и вход в HDrezka на ТВ делает человек.
- **Не коммитит `build/` и `*.wgt`.** Подписанный пакет содержит данные владельца сертификата (email Samsung-аккаунта). `.gitignore` их уже исключает, не ломай это.
- **Не публикует скриншоты экранов «Досмотреть», «Закладки», «Настройки»:** по ним видны история просмотра и тип аккаунта.
- **Не оставляет телевизор включённым, если включал его сам.** Выключить по сети без разрешения на экране ТВ нельзя (см. «Питание ТВ»), поэтому попроси человека выключить пультом.

## Установка: кто что делает

Цель: приложение установлено на ТВ, человек вошёл в HDrezka. Пути ниже для Windows и Tizen Studio в `C:\tizen-studio`.

### 1. Найти телевизор (агент)

Телевизоры Samsung отвечают на `http://<IP>:8001/api/v2/`. Пройди по локальной подсети и найди ответивший адрес: в `device` будут `modelName`, `OS: Tizen`, `PowerState`, `developerMode`, `developerIP`, `networkType`.

Модели примерно с 2021 года (Tizen 6.0+) подходят. Для доступа к локальной сети агенту может понадобиться разрешение пользователя — запроси его.

### 2. Tizen Studio (агент; человек подтверждает UAC)

1. Скачай CLI-установщик, например `https://download.tizen.org/sdk/Installer/tizen-studio_6.1/web-cli_Tizen_Studio_6.1_windows-64.exe`. Новее версия тоже подойдёт.
2. Запусти с повышением прав: `Start-Process <exe> -ArgumentList '--accept-license','C:\tizen-studio' -Verb RunAs -Wait`. **Человек:** подтвердить окно «Разрешить изменения» (UAC).
3. Поставь пакеты через `C:\tizen-studio\package-manager\package-manager-cli.exe install --accept-license <пакет>` для `cert-add-on` и `TV-SAMSUNG-Public`. Менеджер пакетов тоже требует повышения прав: запусти его через `-Verb RunAs`, весь вывод пиши в лог-файл и читай лог. **Человек:** подтвердить UAC.

### 3. Режим разработчика на ТВ (человек)

Попроси человека:

1. На ТВ открыть **Приложения** и набрать на пульте `1 2 3 4 5`.
2. Включить **Developer mode** и в **Host PC IP** ввести IP этого компьютера. Узнай его сам и назови.
3. **Полностью перезагрузить ТВ:** зажать кнопку питания на пульте, пока не появится логотип Samsung. Простое выключение в режим ожидания не подходит.

Проверь сам: в `http://<IP ТВ>:8001/api/v2/` должно быть `developerMode: "1"` и `developerIP` равен IP компьютера.

Затем выполни `C:\tizen-studio\tools\sdb.exe connect <IP ТВ>`. Если телевизор отказывает в подключении даже при включённом режиме разработчика, почти всегда помогает ещё одна полная перезагрузка ТВ.

### 4. Сертификат Samsung (агент запускает, человек входит)

Подпись Samsung привязана к DUID конкретного телевизора, поэтому чужой `.wgt` не подойдёт: каждому нужен свой сертификат.

1. Подключи ТВ через `sdb connect`, чтобы его DUID подставился в сертификат автоматически.
2. Запусти Certificate Manager. Ярлык `certificate-manager.exe` часто не стартует: в `eclipse.ini` прописаны флаги Java 9+, а в комплекте JDK 8. Рабочий способ — запуск из папки `C:\tizen-studio\tools\certificate-manager`:
   ```powershell
   ..\..\jdk\bin\javaw.exe -jar plugins\org.eclipse.equinox.launcher_<версия>.jar -nl en
   ```
   Точное имя jar возьми из папки `plugins`.
3. **Человек:** **+** → **Samsung** → **TV**, имя профиля `RezkaTV` (или другое, тогда передай его в `deploy.ps1 -Profile`). Создать author-сертификат и войти в аккаунт Samsung, когда попросят. Создать distributor-сертификат с уровнем **Public**, DUID подставится сам.
4. Проверь сам: профиль появился в `C:\tizen-studio-data\profile\profiles.xml`.

### 5. Сборка и установка (агент)

```powershell
powershell -ExecutionPolicy Bypass -File deploy.ps1 -Tv <IP ТВ>
```

Скрипт собирает пакет из `config.xml`, `index.html`, `icon.png`, `css/` и `js/`, подписывает профилем, ставит через `sdb push` + `vd_appinstall` и запускает.

- `tizen install` не используется намеренно: он падает на имени пакета с пробелом («Rezka TV.wgt»). Поэтому пакет копируется в `RezkaTV.wgt`.
- После установки приложение остаётся на ТВ насовсем. Режим разработчика нужен только для установки и обновлений.

### 6. Вход в HDrezka (человек)

Попроси человека войти в приложении на ТВ пультом (email и пароль на экранной клавиатуре). Потом проверь сам через отладчик (ниже): `Api.session.logged` должно быть `true`.

Если зеркало по умолчанию `standby-rezka.tv` недоступно в стране человека, адрес меняется на экране входа или в настройках.

## Отладка на телевизоре

```powershell
powershell -ExecutionPolicy Bypass -File tools\tv-debug.ps1 -Tv <IP ТВ>
powershell -ExecutionPolicy Bypass -File tools\cdp.ps1 -Expr "Api.session"
powershell -ExecutionPolicy Bypass -File tools\cdp.ps1 -Expr "Api.listing('/films/', 'last', 1).then(r => r.items.length)"
powershell -ExecutionPolicy Bypass -File tools\cdp.ps1 -Expr "1" -Out screen.png
```

- `tv-debug.ps1` перезапускает приложение в режиме отладки и пробрасывает инспектор на `localhost:9222`. Сначала он убивает приложение: `sdb shell 0 debug` молча виснет, если приложение уже запущено.
- `cdp.ps1` выполняет JS внутри приложения (промисы дожидаются) и может снять скриншот.
- **Скриншот и `visibilityState` работают, только когда экран ТВ включён** и приложение на переднем плане. В режиме ожидания приложение скрыто, и `Page.captureScreenshot` висит.
- Глобальные объекты для отладки: `Api` (запросы и разбор сайта), `Player`, `Screens`, `Nav` (навигация пультом: `Nav.focus(el)`, `Nav.activate()`), `Toast`.
- Отладку в браузере на ПК даёт `tools/serve.ps1`, но там нужен отдельный вход в аккаунт. На ТВ сессия уже есть, поэтому отлаживать на ТВ обычно проще.

## Если «не работает»

Иди по цепочке и не делай выводов заранее:

1. Отвечает ли зеркало с ПК (`curl` на главную). Страница «Вход на HDrezka» без cookies — это нормально.
2. Через отладчик: `Api.session.logged`, `Api.listing(...)`, `Api.details(url)`, `Api.getMovie(...)` / `Api.getStream(...)`.
3. Грузится ли само видео. Создай скрытый `<video>` со ссылкой из `qualities[i].urls` и смотри события `loadedmetadata` / `canplay` / `stalled`. `fetch` из JS и встроенный плеер Tizen ходят в сеть разными путями: fetch может проходить, а плеер стоять.

Известный случай (ноябрь 2026): прогрессивный MP4 с CDN сайта (`voidslam.org`, `stream.voidboost.one` → `strontium.*`) плеер Tizen запускал 15–45 секунд или не запускал вовсе. Тот же файл как HLS (к ссылке на `.mp4` дописывается `:hls:manifest.m3u8`) стартует за ~2 секунды. Поэтому `Api.parseQualities` ставит HLS первым, а `Player` переходит к следующей ссылке, если видео не стартовало за 25 секунд.

## Питание ТВ

- **Включить:** Wake-on-LAN на MAC сетевого адаптера, через который ТВ подключён (смотри `Get-NetNeighbor -IPAddress <IP ТВ>`). Шли пакет на широковещательный адрес подсети, порты 9 и 7. Через несколько секунд `PowerState` в `/api/v2/` станет `on`.
- **Выключить:** только через `ws://<IP>:8001` или `wss://<IP>:8002/api/v2/channels/samsung.remote.control` с `KEY_POWER`. Для этого человек должен один раз нажать «Разрешить» на экране ТВ, иначе канал молчит. Если не вышло, попроси выключить пультом.

## Устройство кода

Чистый JavaScript в стиле ES5, без сборки и зависимостей. UI свёрстан под 1920×1080.

- `js/api.js` — запросы к сайту и разбор HTML. Почти все правки при изменениях сайта — здесь.
- `js/ui.js` — навигация пультом (`.focusable`, `data-group` запоминает фокус в группе, `.scroll-x` / `.scroll-y`), стек экранов, модальные списки, поля ввода.
- `js/player.js` — плеер: качество, субтитры (VTT вручную), перемотка, серии, синхронизация позиции с сайтом.
- `js/app.js` — экраны: главная с меню, карточка фильма, страница актёра, трейлер, вход. Модуль `Marks` строит индекс истории и закладок для пометок на постерах.

Запросы сайта, которыми пользуется приложение (всё под аккаунтом, cookies через `withCredentials`):

| Что | Запрос |
| --- | --- |
| Вход | `POST /ajax/login/` (`login_name`, `login_password`) |
| Ссылки на видео | `POST /ajax/get_cdn_series/` (`action`: `get_movie` / `get_stream` / `get_episodes`) |
| Позиция просмотра; добавить в историю | `POST /ajax/send_save/` |
| История | страница `/continue/`; `POST /engine/ajax/cdn_saves_view.php` (просмотрено, переключатель), `POST /engine/ajax/cdn_saves_remove.php` (удалить) — оба с `id` записи |
| Закладки | страницы `/favorites/…`; `POST /ajax/favorites/` (`action=add_post` переключает фильм в разделе, `action=add_cat` создаёт раздел) |
| Трейлер | `POST /engine/ajax/gettrailervideo.php` (`id`) → встраиваемое видео YouTube |
| Актёр | страница `/person/<id>-<slug>/` |

Проверка синтаксиса через Windows Script Host (`cscript`, JScript) даёт ложное «Ожидается идентификатор» на `.catch(` и на `js/player.js`. Прежде чем верить такой ошибке, сравни с последней рабочей версией файла из git. Надёжная проверка — запуск на ТВ и `tools/cdp.ps1`.

После правок: `deploy.ps1 -Tv <IP>`, затем проверка через `tools/cdp.ps1`.
